## 2. 原理

### 2.1 移位相加与部分积

8×8 无符号乘法：

```
res = Σ_j (in2[j] ? (in1 << j) : 0)     j = 0..7
```

得到 **8 个 16 位部分积** `pp[0..7]`（pp[j] 低 j 位为 0）。
朴素做法是把 8 个部分积用 7 个加法器串行连加：加法链深度随部分积个数线性增长。

### 2.2 进位保存加法器（CSA）——Wallace 树的砖

CSA 是 3:2 压缩器：输入 3 个等长向量 x、y、z，输出 2 个向量 s、q：

```
s = x ⊕ y ⊕ z                    （和，留在本列）
q = xy + xz + yz                 （进位，注意：q 要左移 1 位才有效）
满足：x + y + z = s + (q << 1)
```

关键性质：**每一位独立计算，无横向进位链**——无论多宽，CSA 都是 1 级全加器延迟。
这就是"进位保存（Carry-Save）"的含义：不急着传播进位，先把进位"存"下来。

### 2.3 压缩过程（报告要求的"压缩过程表"）

每层把"3 个向量 → 2 个向量"，向量数逐层减少：

| 层 | 输入向量数 | CSA 用法 | 输出向量数 |
| ---- | ---- | ---- | ---- |
| 初始 | 8（pp0..pp7） | — | 8 |
| 1 | 8 | 2 个 CSA 各压 3 个，剩 2 个直通 | 2×2+2 = **6** |
| 2 | 6 | 2 个 CSA | 2×2 = **4** |
| 3 | 4 | 1 个 CSA 压 3 个，1 个直通 | 2+1 = **3** |
| 4 | 3 | 1 个 CSA | **2** |

8 个部分积经 **4 层 CSA** 压缩到 2 个（s, q<<1），
最后用实验一的 19 位前缀加法器做一次**真正的进位传播加法**得到 16 位结果。

深度对比：朴素连加 7 个加法器串联（线性）vs Wallace 4 层 CSA + 1 次最终加法（对数级压缩）。
面积代价：CSA 用了 7 个向量级压缩器，门数略多于朴素加法树。

| 文件 | 作用 |
| ---- | ---- |
| [lab_2/rtl/CSA.v](../../lab_2/rtl/CSA.v) | 参数化向量级 CSA（`s`、`q` 为未左移原始进位） |
| [lab_2/rtl/MULT8_WALLACE.v](../../lab_2/rtl/MULT8_WALLACE.v) | Wallace 核心：pp 生成 → 4 层 CSA → Lab1 ADDER 求和 |
| [lab_2/rtl/MULT.v](../../lab_2/rtl/MULT.v) | 手册要求的顶层包装（模块名 `MULT`） |
| [lab_2/rtl/MULT_NAIVE.v](../../lab_2/rtl/MULT_NAIVE.v) | 朴素连加对照组 |

阅读核心文件时的四个关键点：

1. **部分积生成**：`pp[j] = in2[j] ? ({8'b0,in1} << j) : 0`，注意零扩展到 16 位
2. **进位左移的位置**：本实现约定 CSA 输出**未左移的 q**，
  左移在送入下一级时完成：`csa(.x(s1), .y({q1[W-2:0],1'b0}), ...)`
  ——这是最容易错的地方：`q` 必须左移 1 位，且移位后仍在 16 位内（最高位进位丢弃，
  因为 8×8 无符号乘法结果 < 2^16，不会真溢出）
3. **直通向量**：每层没被 CSA 压到的向量（如第 1 层的 pp6、pp7）要原样传到下一层
4. **最终加法位宽**：`s` 与 `q<<1` 零扩展到 19 位送入实验一 ADDER，`cin=0`，
  取 `sum[15:0]`；`cout` 理论恒 0，可用于自检

## 4. 验证方案与结果

文件：[lab_2/tb/tb_MULT.v](../../lab_2/tb/tb_MULT.v)

**方法**：定向用例 + **全量遍历**。8 位乘法器输入空间只有 256×256=65536 组，
仿真秒级完成——**小位宽电路应优先做穷举验证**，这是功能正确性的最强证据。

| 类别 | 内容 |
| ---- | ---- |
| 定向 9 组 | 0×0、0×N、1×N、255×255（最大）、255×1、128×2（进位传播）、幂次 |
| 全量 65536 组 | `for a in 0..255, b in 0..255`，与 `a*b` 逐一比对 |

```bash
cd lab_2/sim
iverilog -g2005 -o simv ../rtl/MULT.v ../rtl/MULT8_WALLACE.v ../rtl/MULT_NAIVE.v ../rtl/CSA.v ../../lab_1/rtl/ADDER.v ../tb/tb_MULT.v
vvp simv        # 期望: Errors: 0 / RESULT: PASS
```

实测：**65536 组全部正确**（Wallace 与朴素两个 DUT 同时过）。

## 5. 综合结果与解读

```bash
cd lab_2/syn && yosys synth.ys   # 分别综合两个设计，生成 stat 与 ltp
```

| 设计 | cells | 最长拓扑路径 | 理论结构 |
| ---- | ---- | ---- | ---- |
| Wallace 树 | **381** | **28 级** | 4 层 CSA + 前缀加法 |
| 朴素连加 | **338** | **37 级** | 7 个加法器串联 |

**思考题（理论层数与实际性能的关系）参考分析**：

1. 本组实测与理论方向一致：Wallace 路径短 24%（28 vs 37），面积多 13%——典型的面积换速度
2. 但绝对级数 ≠ 理论层数：ABC 综合器对组合逻辑做**全局重构**
  （与/或/异或混合重新分解、缓冲插入），理论"4 层 CSA"在门级网表中已不可辨认
3. 结论正如手册所述："较少的理论层数并不保证在所有工艺或 FPGA 上都更快"——
  理论分析给出**趋势**（对数 vs 线性），具体数值必须实测；
  位宽越大（如 32×32），Wallace 的结构优势越明显

**流程注意**：综合脚本必须 `synth -top MULT -flatten`，
让 ABC 在整平后的设计上全局优化。若 `synth` 后再 `flatten`，
ABC 只能逐模块映射，跨模块边界无法优化，LTP 数据将明显失真。

## 7. 常见问题

| 问题 | 原因/解决 |
| ---- | ---- |
| 结果总是差一倍或差 2 倍 | `q` 忘记左移 1 位（或重复左移）——CSA 进位处理的常见错误 |
| 大数相乘结果错、小数对 | 部分积没零扩展到 16 位，或移位后被截断 |
| 仿真 PASS 但综合后不对 | 检查是否写了不可综合语句（本实验应全组合逻辑） |
| LTP 数据异常偏大 | 综合脚本没加 `-flatten`，见第 5 节流程坑 |
| `Unknown module: ADDER` | 编译漏带 `../../lab_1/rtl/ADDER.v`（本实验复用实验一） |
| 全量遍历仿真很慢 | 正常约数秒；若卡顿检查 tb 是否每条都 $display（应只在出错时打印） |

## 8. 与课程路径的关系

本实验是"加法器→乘法器→矩阵计算阵列"的中间环：

- **向后依赖**：最终求和复用实验一 ADDER（`../../lab_1/rtl/ADDER.v`）
- **向前支撑**：实验三（复用版）的 PE 直接实例化本实验的

  一个 PE = 你的乘法器 + 你的加法器 + 3 个寄存器
